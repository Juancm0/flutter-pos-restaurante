# Sistema EVE - Manual de Usuario

## Guía Completa para Administradores y Trabajadores

---

# 📱 Introducción

**Sistema EVE** es una aplicación de gestión para restaurantes y negocios de comida que permite:
- Tomar órdenes desde mesas o para llevar
- Gestionar cocina y bar por separado
- Cobrar y procesar pagos
- Administrar menú, inventario y personal

---

# 🔐 Inicio de Sesión

1. Abre la aplicación
2. Ingresa tu **correo electrónico** 
3. Ingresa tu **contraseña**
4. Toca **"Iniciar Sesión"**

> **Nota:** Tu administrador te proporcionará las credenciales de acceso.

---

# 👨‍🍳 GUÍA PARA MESEROS

## Panel Principal

Al iniciar sesión verás 3 pestañas:

| Pestaña | Función |
|---------|---------|
| **Mesas** | Ver todas las mesas disponibles y ocupadas |
| **Mis Órdenes** | Tus órdenes activas |
| **Para Llevar** | Órdenes para llevar |

---

## Tomar una Orden en Mesa

### Paso 1: Seleccionar Mesa
1. Ve a la pestaña **"Mesas"**
2. Las mesas muestran su estado con colores:
   - 🟢 **Verde** = Disponible
   - 🟡 **Amarillo** = Ocupada
   - 🔴 **Rojo** = Pendiente de cobro
3. Toca la mesa donde quieres tomar la orden

### Paso 2: Agregar Productos
1. Usa los filtros **Combi/Bar/Todos** para encontrar productos
2. Usa las categorías para filtrar más
3. **Toca el producto** que deseas agregar
4. Se abrirá una ventana donde puedes:
   - Seleccionar **cantidad** (botones + y -)
   - Agregar **notas especiales** (ej: "Sin cebolla")
   - Usar los **chips rápidos** para notas comunes
5. Toca **"Agregar a la Orden"**

### Paso 3: Revisar y Confirmar
1. La barra inferior muestra el **total** y **cantidad de items**
2. Toca **"VER"** para revisar la orden completa
3. Puedes editar cantidades o eliminar productos
4. Toca **"Confirmar Orden"**

---

## Tomar Orden Para Llevar

1. Ve a la pestaña **"Para Llevar"**
2. Toca **"Nueva"**
3. Ingresa:
   - **Nombre del cliente**
   - **Teléfono** (para llamar cuando esté listo)
4. Agrega los productos igual que en mesas
5. Confirma la orden

---

## Mis Órdenes

En esta pestaña ves todas tus órdenes activas:

| Color | Estado |
|-------|--------|
| 🟡 Amarillo | **Pendiente** - En espera de cocina |
| 🔵 Azul | **Preparando** - Cocina trabajando |
| 🟢 Verde | **Lista** - ¡Lista para entregar! |

### Notificaciones
- Recibirás una **notificación** cuando tu orden esté lista
- Las órdenes listas parpadean para llamar tu atención

---

## Entregar Orden

1. Cuando una orden esté **lista** (verde)
2. Lleva los productos a la mesa
3. Toca **"Entregar"** en la orden
4. La orden pasa a caja para cobro

---

# 🍳 GUÍA PARA COCINA

## Panel de Cocina

Verás dos columnas:
- **Pendientes** (izquierda) - Órdenes nuevas esperando
- **Preparando** (derecha) - Órdenes en proceso

---

## Flujo de Trabajo

### 1. Recibir Orden Nueva
- Las órdenes nuevas aparecen en **Pendientes**
- Verás: número de mesa, tiempo transcurrido, items

### 2. Comenzar a Preparar
1. Revisa los items de la orden
2. **¡Atención a las notas!** (marcadas con ⚠️)
3. Toca **"Preparar"**
4. La orden pasa a **"Preparando"**

### 3. Marcar como Lista
1. Cuando termines todos los items
2. Toca **"Listo"**
3. El mesero recibirá notificación

---

## Indicadores de Tiempo

El temporizador cambia de color según el tiempo:

| Color | Tiempo | Acción |
|-------|--------|--------|
| 🟢 Verde | 0-10 min | Normal |
| 🟡 Naranja | 10-20 min | ¡Apurar! |
| 🔴 Rojo | +20 min | ¡Urgente! |

---

## Items con Notas Especiales

- Los items con notas tienen un **fondo resaltado**
- Muestra un icono ⚠️ de advertencia
- Lee la nota cuidadosamente (ej: "Sin cebolla", "Término 3/4")

---

# 🍺 GUÍA PARA BAR

## Panel de Bar

Similar a cocina, pero solo ves **items de bebidas**.

---

## Flujo de Trabajo

1. **Órdenes Pendientes** - Nuevas bebidas por preparar
2. Toca **"Preparar"** para comenzar
3. Prepara las bebidas
4. Toca **"Listo"** cuando termines

> **Nota:** Las órdenes mixtas (comida + bebidas) se muestran en cocina Y bar por separado. Cada uno marca su parte como lista.

---

# 💰 GUÍA PARA CAJERO

## Panel de Caja

Verás las órdenes listas para cobrar, organizadas por:
- **Combi** - Órdenes de comida
- **Bar** - Órdenes de bebidas
- **Todas** - Todas las órdenes

---

## Cobrar una Orden

### Paso 1: Seleccionar Orden
1. Encuentra la orden en la lista
2. Toca la orden para ver detalles

### Paso 2: Procesar Pago
1. Verifica el **total** con el cliente
2. Toca **"Cobrar"**
3. Selecciona método de pago:
   - 💵 **Efectivo**
   - 💳 **Tarjeta**
4. Confirma el cobro

### Paso 3: Confirmación
- La orden se marca como **pagada**
- La mesa queda **disponible** nuevamente

---

## Cancelar una Orden

1. Toca la orden
2. Toca **"Cancelar"**
3. Confirma la cancelación

> **Nota:** Solo se pueden cancelar órdenes pendientes.

---

# 👔 GUÍA PARA ADMINISTRADORES

## Panel de Administración

Tienes acceso a:
- **Dashboard** - Resumen general
- **Menú** - Gestión de productos
- **Inventario** - Control de stock
- **Mesas** - Configuración de mesas
- **Usuarios** - Gestión de personal
- **Reportes** - Estadísticas de ventas

---

## Gestión de Menú

### Agregar Producto
1. Ve a **Menú**
2. Toca **"+"**
3. Completa:
   - Nombre
   - Descripción
   - Precio
   - Categoría
   - Sección (Combi/Bar)
   - Tiempo de preparación
   - Ingredientes (para control de inventario)
4. Toca **"Guardar"**

### Editar Producto
1. Toca el producto
2. Modifica los datos
3. Guarda cambios

### Disponibilidad
- Usa el switch para marcar productos como **no disponibles**
- Útil cuando se agota un ingrediente

---

## Control de Inventario

### Colores de Stock

| Color | Significado |
|-------|-------------|
| 🟢 Verde | Stock suficiente |
| 🟡 Amarillo | Stock bajo |
| 🔴 Rojo | Stock crítico - ¡Reponer! |

### Ajustar Stock
1. Ve a **Inventario**
2. Toca el ingrediente
3. Ingresa la nueva cantidad
4. Guarda

---

## Gestión de Usuarios

### Crear Usuario
1. Ve a **Usuarios**
2. Toca **"+"**
3. Ingresa:
   - Nombre
   - Correo electrónico
   - Contraseña
   - Rol (Mesero, Cocina, Bar, Cajero, Admin)
4. Toca **"Crear"**

### Roles Disponibles

| Rol | Permisos |
|-----|----------|
| **Mesero** | Tomar órdenes, ver mesas |
| **Cocina** | Ver y gestionar órdenes de comida |
| **Bar** | Ver y gestionar órdenes de bebidas |
| **Cajero** | Cobrar órdenes |
| **Admin** | Acceso total al sistema |

---

## Reportes

### Tipos de Reportes

1. **Ventas** - Total vendido por período
2. **Productos** - Items más vendidos
3. **Ingredientes** - Consumo de inventario

### Filtrar por Período
- Hoy
- Esta semana
- Este mes
- Rango personalizado

# ❓ Preguntas Frecuentes

## ¿Qué hago si una orden tiene un error?
- Si está **pendiente**: El mesero puede editarla
- Si ya está **preparándose**: Comunicarse con cocina directamente

## ¿Cómo cancelo una orden?
- Solo el **Cajero** o **Admin** puede cancelar órdenes

## ¿Por qué no veo ciertos productos?
- El admin puede marcar productos como **no disponibles**

## ¿Qué pasa si se va el internet?
- Las órdenes pendientes se guardarán cuando vuelva la conexión
- Recomendación: tener conexión estable
